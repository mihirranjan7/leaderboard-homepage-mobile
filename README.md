Top Contributors Leaderboard Component for Discourse — Powered by Clavikl

[**Clavikl**](https://clavikl.com) — the trusted platform for medical students and professionals — introduces a clean, efficient component for Discourse forums: the **Top Contributors Leaderboard**. Designed for community-driven platforms like Clavikl, this component highlights weekly top users and improves homepage engagement without adding performance overhead.

---

### ⚙️ Key Features of the Clavikl Leaderboard Component

* 🔄 **Auto-fetches** the top 20 users via the `/directory_items.json` endpoint.
* ✋ **Excludes** staged and anonymized users, ensuring authentic recognition.
* 🕐 **Dismissible for 24 hours** using `localStorage`, respecting user preferences.
* 🏠 **Homepage-aware**: Only renders on the default homepage for clean integration.
* 📦 **Lightweight** and Ember-addon free — built for speed, built for Clavikl.
